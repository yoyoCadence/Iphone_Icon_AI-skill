# Metaphors by category — the cliché, and the twists that still read at 29pt

Use this as a starting list, not a menu. The twist is what makes the icon ownable; the cliché is
what makes it recognisable. Good icons keep enough of the cliché to be read, and change enough to
be remembered. Combine with a style from `styles.md`.

## How to pick in 60 seconds

1. Write the essence in five words.
2. Take the category's cliché; ask "which *action* or *moment* of this object is the app really about?"
3. Render that moment (rising, breaking, splitting, lighting) — the action is the twist.
4. Draw the silhouette as a black blob at 64px in your head. If it needs a caption, simplify.

## Letterforms are a fallback, not a default

A monogram wins only when the object metaphors all fail the 29pt test or the brand already *is*
the letter. Even then, apply a trick (see style F) — a bare letter on a gradient is a placeholder.
